cinder-rescue

Ready
  1. Unplug the cable and switch the player off. If it keeps restarting, hold Power about 10 seconds.
  2. Hold Play and Volume − together.
  3. Plug the cable in, and let go when this box disappears.

Back up the player

Copies everything a broken update can damage (2.7 GB, about 21 minutes) into a new file next to this program. It only reads; nothing on the player changes. Take one while the player works, and keep it.

Put a backup back

Only onto the player the backup came from, and never your music. It compares first and writes only what differs, then reads every piece back.

Connection

Test that this computer can reach the player in download mode. It reads the chip and the memory's ID, then restarts the player.

USB driver (Windows)

Windows needs a driver for the player in download mode. If the test says the player "cannot be opened", install it here; Windows asks for permission. wbrt's driver works too.
